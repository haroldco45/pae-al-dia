# PAE al Día

App ciudadana (PWA) de **Vibras Positivas HM** para seguir día a día el Programa de Alimentación Escolar (PAE) de Colombia y la Unidad Alimentos para Aprender.

- Sección **Hoy** con búsqueda de noticias en vivo al abrir y botón **Actualizar**.
- Robot de GitHub Actions (`.github/workflows/robot.yml`) que trae noticias reales y videos del canal oficial cada 30 minutos y los guarda en `data/noticias.json`.
- Sección **Casos** en todo Colombia (Sincelejo $36.324 millones, Contraloría nacional, Santa Fe de Antioquia), con lo último del robot por caso y formulario para reportar casos nuevos por WhatsApp.
- **Derecho de petición a todos los entes de una sola vez**: escoge el caso y la carta sale para Alcaldía, UNGRD, UApA, Contraloría, Procuraduría, Fiscalía, Concejo y Personería (correo o Gmail con todos los destinatarios).
- Español e inglés.

URL: https://pae-al-dia.netlify.app/

App independiente; no es una app del Gobierno.
